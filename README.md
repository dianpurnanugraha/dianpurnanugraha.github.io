# Portofolio — Dian Purna Nugraha, S.Kom.

Website portofolio statis bilingual untuk menampilkan profil, pengalaman, layanan, keahlian, proyek, artikel Insight, dan kontak profesional sebagai **E-commerce Operations & Business Operations Specialist**.

**Live:** [dianpurnanugraha.my.id](https://dianpurnanugraha.my.id)

## Ringkasan

- 23 halaman detail proyek
- 6 artikel Insight
- 5 kategori proyek
- Bahasa Indonesia dan Inggris
- Responsive untuk desktop dan perangkat mobile

## Struktur Halaman Utama

| File | Deskripsi |
|---|---|
| `index.html` | Halaman utama dan ringkasan profil |
| `about.html` | Profil, nilai kerja, dan informasi tentang saya |
| `services.html` | Layanan profesional |
| `skill.html` | Kompetensi, skill, dan tools |
| `experience.html` | Riwayat pengalaman kerja |
| `project.html` | Daftar 23 proyek dengan filter kategori |
| `insight.html` | Daftar artikel dan insight profesional |
| `contact.html` | Kontak dan tautan sosial media |

## Tech Stack

- HTML5 dan CSS3 tanpa framework
- JavaScript vanilla
- Sistem terjemahan ID/EN berbasis kamus JavaScript dan `localStorage`
- Font Awesome 6.5.1
- Google Fonts: Poppins dan Inter
- Gambar WebP dengan lazy loading
- GitHub Pages dan custom domain

## Struktur Aset

- `assets/css/` — stylesheet situs
- `assets/js/` — navigasi, galeri, filter, slider, dan sistem i18n
- `assets/img/` — gambar profil, proyek, dan artikel
- `assets/files/` — dokumen yang dapat diunduh

## Menjalankan Secara Lokal

Jalankan server lokal dari direktori utama repository:

```bash
python3 -m http.server 8000
```

Kemudian buka [http://localhost:8000](http://localhost:8000).
